# Cloud Based Media File Storage Service

A full-stack cloud file storage and sharing application inspired by Google Drive.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- TanStack Query
- Axios

### Backend
- Python
- FastAPI
- SQLAlchemy
- Pydantic
- JWT Authentication

### Database
- PostgreSQL
- Supabase

### Object Storage
- Supabase Storage

## MVP Features

- User registration and login
- Folder management
- File upload and download
- File rename and move
- Trash and restore
- File sharing
- Viewer and Editor permissions
- Public share links
- Search
- Starred files

## Phase 2

- File version history
- File previews
- Activity logs
- Tags and labels
- Storage quota management

## Architecture

React → FastAPI → PostgreSQL
                  ↓
            Supabase Storage
